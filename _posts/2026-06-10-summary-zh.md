## [谷歌发布开源 DiffusionGemma 模型，实现快速文本生成](https://simonwillison.net/2026/Jun/10/diffusiongemma/#atom-everything) ⭐️ 9.0/10

谷歌已将其此前处于实验阶段的 Gemini Diffusion 模型作为开源、采用 Apache 2 许可的 Gemma 模型发布，名为`diffusiongemma-26B-A4B-it`，用于快速文本生成，并通过 NVIDIA 的 NIM 云 API 提供免费托管。 此次发布通过开放一个快速文本生成模型，并提供免费托管，极大地促进了 AI 领域的广泛采用和创新，降低了开发者和研究人员的进入门槛。其对效率的关注对于未来的 AI 应用至关重要，尤其是在边缘设备和近实时使用场景中。 该模型名为`google/diffusiongemma-26B-A4B-it`，采用 Apache 2 许可发布，并展示了快速的文本生成速度，此前预览版达到每秒 857 个 token，目前使用 NVIDIA API 时至少达到每秒 500 个 token。NVIDIA 通过其 NIM 云 API 提供该模型的免费托管，但需要创建账户并进行电话验证。

## [Anthropic Claude Fable 5 将悄然限制对竞争性 LLM 开发的帮助](https://simonwillison.net/2026/Jun/10/if-claude-fable-stops-helping-you/#atom-everything) ⭐️ 9.0/10

Anthropic 为其 Claude Fable 5 和 Mythos 5 发布的新系统卡披露了一项政策，即模型将通过提示修改和转向向量等方法，悄然限制其对开发竞争性前沿大型语言模型的用户的有效性。尽管使用 Claude 开发竞争模型已违反其服务条款，但这标志着 Anthropic 首次宣布此类不可见的干预措施。 这项政策引发了关于人工智能行业内透明度、信任和公平竞争的重大伦理担忧，可能扼杀创新并为开发者制造不公平的竞争环境。用户对这些干预措施毫不知情，可能会损害对人工智能工具及其提供商的信任。 这些安全措施将通过提示修改、转向向量或参数高效微调（PEFT）等方法限制模型有效性，且用户不可见，这意味着 Fable 5 不会回退到其他模型或明确通知用户。Anthropic 估计这些干预措施将影响约 0.03%的流量，集中在不到 0.1%的组织中。

rss · Simon Willison · Jun 10, 00:37
