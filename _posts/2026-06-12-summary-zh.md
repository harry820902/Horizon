Vercel AI 库发布了 `ai@6.0.203` 版本，这是一个重要的补丁，通过修复与 URL 验证和文件下载相关的多个服务器端请求伪造 (SSRF) 漏洞，显著增强了安全性，同时还加强了流文本处理并默认隐藏了 UI 消息流中的服务器错误详情。 此次更新意义重大，因为 SSRF 漏洞可能允许攻击者访问内部网络资源或敏感数据，因此修复这些漏洞对于使用 `vercel/ai` 库构建的应用程序的安全性至关重要，并能防止潜在的数据泄露。 此补丁通过剥离主机名中的尾随点、完全扩展 IPv6 地址以检测嵌入的私有 IPv4 目标，以及在重定向期间手动重新验证每个跳转来加强 URL 验证，从而防止不安全的请求，同时还阻止了多个保留的 IP 范围。此外，默认的 `onError` 回调现在返回一个通用消息，防止敏感的服务器异常详情暴露给客户端。

## [Vercel AI 5.0.200 发布，包含关键 SSRF 和安全修复](https://github.com/vercel/ai/releases/tag/ai%405.0.200) ⭐️ 8.0/10

Vercel AI 5.0.200 版本已发布，引入了关键安全修复，以加强下载 URL 的服务器端请求伪造 (SSRF) 防护，抵御包括主机名操纵、IPv6 地址解码问题和重定向漏洞在内的多种绕过技术。此外，它还增强了流文本处理以防止原型污染，并默认从 UI 消息流中删除了服务器错误详情。 这些修复非常重要，因为 SSRF 漏洞可能允许攻击者访问内部系统、敏感数据或执行未经授权的操作，因此此补丁对于增强使用 Vercel AI 库的应用程序的安全态势至关重要。服务器错误详情的默认隐藏也防止了意外向最终用户泄露信息。 SSRF 防护曾被主机名中的尾随点、未解码的嵌入私有 IPv4 地址的 IPv6 地址（如 `::127.0.0.1`、`::ffff:0:127.0.0.1`、`64:ff9b::127.0.0.1`）以及在跟随重定向后才进行验证的问题所绕过。此次更新现在会去除尾随点，完全扩展 IPv6 地址，并手动重新验证每个重定向跳点，对于不透明响应在服务器端会拒绝重定向。

## [Vercel AI SDK 修复凭证泄露漏洞](https://github.com/vercel/ai/releases/tag/%40ai-sdk/replicate%402.0.35) ⭐️ 8.0/10

Vercel 的 AI SDK，特别是 `@ai-sdk/replicate@2.0.35` 及其他提供商客户端，发布了一个关键安全补丁 (bfa5864)，通过确保 API 密钥仅在遵循提供商提供的同源 URL 时发送，从而防止凭证泄露。此修复解决了 API 密钥可能被发送到 API 响应中指定的任意非同源主机的漏洞。 此补丁至关重要，因为它修复了一个可能导致敏感 API 密钥泄露的关键安全漏洞，这可能危及与广泛使用的 Vercel AI SDK 集成的多个 AI 提供商的用户账户和数据。它强调了 AI 开发中安全凭证管理的重要性，并防止了在提供商响应被篡改时可能发生的供应链攻击。 该漏洞源于提供商客户端在未验证主机来源的情况下，直接从 API 响应中获取 URL（如 `polling_url`、`urls.get`、`result_url`）并重用认证头或附加 API 密钥。此修复引入了 `@ai-sdk/provider-utils` 中的 `isSameOrigin` 辅助函数，以确保凭证仅在所遵循的 URL 与提供商配置的 API 源同源时才附加，对异源请求则不携带凭证。
